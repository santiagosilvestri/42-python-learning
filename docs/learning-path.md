## Learn the ideas before building the projects

This roadmap is meant for students who want to become comfortable with Python concepts **before** solving larger programming problems independently. You can start at chapter 00 or jump to a chapter that covers a specific knowledge gap.

A good routine for each chapter is to **read → predict → run → modify → explain → practice**. Writing code is essential, but explaining why the code behaves as it does is what makes knowledge transferable.

## How to tell whether you're ready to move on

Before leaving a chapter, try to:

1. **Describe** its essential ideas in your own words without copying a definition.
2. **Predict** the behavior of a short example before running it.
3. **Modify** a working program to meet a slightly different goal.
4. **Debug** an intentionally broken example and explain the cause.
5. **Create** a small, original program that combines two or more concepts.

These are self-assessment prompts, not a substitute for doing your own projects.
