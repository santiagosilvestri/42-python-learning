# 42 Python Learning Path

**Learn Python. Practice independently. Build with confidence.**

An independent, hands-on learning guide for students preparing to work on Python projects at 42. This repository is designed to help you understand essential concepts, experiment with code, and develop the problem-solving skills to tackle projects on your own.

> **Work in progress:** I'm building this guide in public, one useful update at a time.

## How to use this guide

1. **Learn** — Start with the concepts and understand *why* they matter.
2. **Explore** — Run small Python examples and change them to see what happens.
3. **Practice** — Work through original exercises without looking for a solution first.
4. **Reflect** — Debug, test edge cases, and explain your reasoning.
5. **Build** — Apply what you learned to your own projects.

The goal is not to memorize solutions. It's to become confident enough to design and write your own.

## What each chapter will include

- **Core concepts:** short explanations with practical examples.
- **Code lab:** small, runnable snippets you can experiment with.
- **Practice:** original exercises with increasing difficulty.
- **Common pitfalls:** frequent mistakes and debugging techniques.
- **Knowledge check:** questions to test your understanding.
- **Next steps:** suggestions for independent exploration.

## Learning principles

- **Understand before copying.** Read code critically and test your assumptions.
- **Practice before checking answers.** Make an attempt, even if it doesn't work yet.
- **Explain your decisions.** If you can explain your code, you probably understand it better.
- **Keep it practical.** Every concept should lead to something you can run, modify or build.
