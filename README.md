# 42 Python Learning Path

**Learn Python. Practice independently. Build with confidence.**

An independent, hands-on learning guide for students preparing to work on Python projects at 42. Learn the concepts, experiment with small examples, and build the problem-solving skills to tackle projects on your own.

> **Work in progress:** This guide is being built in public, one useful update at a time. Chapter 00 now includes its first lesson; other chapters remain outlines.

## Start here

- **[Learning path](docs/learning-path.md)** — See the complete sequence, expected skills and how to choose your next chapter.
- **[Chapter index](modules/README.md)** — Jump to any chapter and move between them.
- **[Getting started](docs/getting-started.md)** — Install Python, run your first script and learn how to use this guide.

## How to learn with this guide

1. **Learn** — Understand a concept and why it matters.
2. **Explore** — Run short examples and make predictions before changing them.
3. **Practice** — Try original exercises without immediately searching for answers.
4. **Reflect** — Debug edge cases and explain your decisions aloud.
5. **Build** — Use your knowledge to solve your own projects independently.

## What complete chapters will include

- **Concepts:** explanations written from scratch with clear terminology.
- **Examples:** small, runnable programs that illustrate one idea at a time.
- **Practice:** original problems with increasing difficulty.
- **Common mistakes:** debugging and design pitfalls.
- **Knowledge checks:** questions to answer without looking up a solution.
- **Next steps:** directions for deeper independent practice.

## Learning principles

- **Understand before copying.** Learn to reason from behavior, not just syntax.
- **Practice before checking answers.** Struggling productively is part of learning.
- **Explain your decisions.** Code should be understandable, not merely executable.
- **Build independence.** This resource helps you prepare; your own solutions remain your work.
