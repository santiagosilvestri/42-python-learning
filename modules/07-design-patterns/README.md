# 07 — Design Patterns

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Use small design patterns to keep object creation and behavior easy to replace.

## What you will learn

- Identify repeated design problems rather than memorizing patterns.
- Encapsulate object creation where it adds clarity.
- Swap algorithms or behavior behind a stable interface.
- Compare pattern-based designs with simpler alternatives.

## Concepts to explore

- Factory pattern
- Strategy pattern
- Interfaces
- Composition over inheritance

## Think before coding

1. When does a factory help more than calling a constructor directly?
2. How can an object change its behavior without a long chain of `if` statements?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
