# 00 — Python Fundamentals

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Start by learning to express small ideas in Python before combining them into larger programs.

## What you will learn

- Choose appropriate values and types for a problem.
- Use conditions, loops and functions to express clear logic.
- Trace what a program does, including its recursive calls.
- Break a simple problem into steps before writing code.

## Concepts to explore

- Variables and assignment
- Expressions and operators
- Control flow
- Functions and recursion

## Think before coding

1. When would you use a function instead of repeating a block of code?
2. What must be true for a recursive function to stop?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
