# 04 — Files and I/O

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Connect Python programs to information outside their own process while keeping resource handling reliable.

## What you will learn

- Read and write text files using appropriate modes.
- Explain why text encoding matters.
- Use `with` to manage a file resource safely.
- Handle common I/O errors and distinguish output streams.

## Concepts to explore

- open() and file modes
- Text encoding
- Context managers
- stdout and stderr

## Think before coding

1. Why is `with open(...)` usually safer than leaving a file open?
2. When should a program write to standard error rather than standard output?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
