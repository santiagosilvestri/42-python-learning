# 05 — Advanced Object-Oriented Python

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Design components that can change independently while still working together.

## What you will learn

- Recognize behavior shared by multiple implementations.
- Compare inheritance-based abstraction with structural typing.
- Use protocols to describe required behavior.
- Favor composition when it makes code easier to extend.

## Concepts to explore

- Abstract base classes
- Polymorphism
- Protocols
- Duck typing and composition

## Think before coding

1. Can unrelated classes support the same operation? How?
2. What is the difference between an ABC and a protocol?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
