# 03 — Data Structures

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Choose and transform collections based on the kind of data and access patterns you need.

## What you will learn

- Compare lists, tuples, sets and dictionaries.
- Write readable comprehensions and recognize when a loop is clearer.
- Use iteration without unnecessarily copying data.
- Explain how a generator produces values on demand.

## Concepts to explore

- Lists and tuples
- Sets and dictionaries
- Comprehensions
- Iterators and generators

## Think before coding

1. Why might a set be useful for tracking unique values?
2. How does a generator differ from a list in memory usage?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
