# 06 — Modules and Packages

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Understand how Python finds code and how to organize multiple files into maintainable packages.

## What you will learn

- Separate a program into modules with clear responsibilities.
- Explain absolute and relative imports.
- Identify what package initializers do and do not do.
- Run and debug code while understanding import context.

## Concepts to explore

- Modules and packages
- Namespaces
- Absolute and relative imports
- __init__.py and python -m

## Think before coding

1. Why can an import work in one execution context but fail in another?
2. What is the practical difference between a module and a package?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
