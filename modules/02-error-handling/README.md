# 02 — Error Handling

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Learn how programs fail, how to handle expected problems, and when to let errors surface.

## What you will learn

- Distinguish normal return values from raised exceptions.
- Handle specific errors without hiding unrelated bugs.
- Create meaningful error messages and custom exception types.
- Use cleanup logic reliably when operations fail.

## Concepts to explore

- try / except
- raise
- Exception classes
- else and finally

## Think before coding

1. Why is catching every exception usually risky?
2. What should be cleaned up when a file operation fails?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
