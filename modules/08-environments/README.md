# 08 — Python Environments

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Make Python projects easier to install, run and reproduce across machines.

## What you will learn

- Explain why projects use isolated virtual environments.
- Install and inspect dependencies safely.
- Understand the difference between a package and a Python module.
- Recognize configuration and environment-related problems.

## Concepts to explore

- venv
- pip and dependencies
- Package metadata
- Environment variables

## Think before coding

1. Why can code run on one computer but fail on another?
2. What problem does a virtual environment solve?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
