# 09 — Data Validation

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Build models that check incoming data before the rest of a program relies on it.

## What you will learn

- Define typed data models with Pydantic.
- Add field-level constraints and sensible defaults.
- Validate related fields and nested data safely.
- Interpret and report validation errors clearly.

## Concepts to explore

- BaseModel
- Field and constraints
- Nested models
- model_validator

## Think before coding

1. How is type annotation different from runtime validation?
2. When would validation need to consider more than one field?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
