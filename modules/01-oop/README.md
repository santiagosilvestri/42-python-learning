# 01 — Object-Oriented Programming

> **Status: Outline.** The complete lessons, runnable examples and practice labs will be added in a later update.

Model a problem with objects that hold state and provide useful behavior.

## What you will learn

- Explain the difference between a class and an instance.
- Initialize objects and distinguish instance attributes from class attributes.
- Design methods that maintain valid object state.
- Recognize when inheritance helps and when composition is simpler.

## Concepts to explore

- Classes and instances
- self and __init__
- Attributes and methods
- Inheritance and super()

## Think before coding

1. Why is `self` passed to instance methods?
2. When would two instances need separate copies of an attribute?

These prompts are for reflection, not graded tests. Try answering them in your own words before searching for examples.
